# Thermostat-for-tortoise
This project was developed as a Sulcata tortoise monitoring device for beginners. It features temperature and humidity sensors, an LCD display, and a small fan to regulate moisture levels.

## Tools & Materials
**Hardware**:

- Microcontroller: Arduino Uno R3 (Open-source hardware)

- Sensors & Modules:
  -  DHT11 Temperature & Humidity Sensor 2 pieces
  -  16x2 LCD Display (I2C) 
  -  DC Cooling Fan \ 12 volts 
  -  Relay 5DC 2 Channels
-  Battery
   -  21700, 5000 mAh, 3.7V, 3 pieces
   -  5v, 1 pieces
  

**Software & Open-Source Libraries**:

- Arduino IDE (GPL)

- Adafruit DHT Sensor Library (MIT License)

- LiquidCrystal_I2C Library (LGPL / MIT License)
